# /sky-readme

Vurgu: `$ARGUMENTS`

1. `sky:sky-tech-writing` ve `sky:sky-architecture-docs` skill'lerini yükle.
2. Koddan topla (varsayma): `package.json`/manifest scriptleri → komutlar; `.env.example`/env doğrulama → ortam değişkenleri; klasör yapısı; dağıtım yapılandırması.
3. Mevcut README varsa iyileştir (üzerine körlemesine yazma); mimari için 1 Mermaid diyagramı (gerçek bileşen adları).
4. Yapı: tek cümle ne + demo/ekran görüntüsü yeri → hızlı başlangıç (≤ 5 komut) → mimari (diyagram + 5 madde) → komutlar → ortam değişkenleri → dağıtım → katkı/kurallar bağlantısı.
5. Yazdığın komutları mümkünse doğrula; gizli bilgi yok; `sky-doc-writer` yöntemi ile de yapılabilir.
6. Kısa ve tarayılabilir tut.
